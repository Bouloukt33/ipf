# Landing Page - Next.js 14 SSG

Site vitrine SEO-optimisé pour "5 Secondes Chrono".

## Stack Technique

- **Next.js 14** - Framework React (App Router)
- **TypeScript** - Typage statique
- **Tailwind CSS** - Styling
- **Static Site Generation (SSG)** - Performance maximale

## Pages

```
app/
├── page.tsx              # Accueil
├── tarifs/page.tsx       # Grille tarifaire
├── contact/page.tsx      # Formulaire contact
├── outils/page.tsx       # Présentation outils
├── a-propos/page.tsx     # À propos Le Carré PRO
└── mentions-legales/     # Mentions légales & CGV
```

## Fonctionnalités

- ✅ SEO optimisé (meta tags, sitemap, robots.txt)
- ✅ Performance Lighthouse 100
- ✅ Responsive mobile-first
- ✅ Génération statique à la build
- ✅ Formulaire contact avec validation
- ✅ Intégration avec Auth0 (boutons connexion/inscription)

## Scripts

```bash
pnpm dev      # Développement
pnpm build    # Build statique
pnpm start    # Serveur production
pnpm lint     # Linting
```
